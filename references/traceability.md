# 阶段溯源记录

每个界面长期维护两份固定 UTF-8 Markdown 说明；新建、源稿更新、整理稿人工修正、正式重导出及适配修订均在原文件追加，不按轮次另建同类 MD。

“历史记录”均指当前这两份说明内已有的内容，不另建一套说明。只处理某个阶段时仅更新对应说明；源更新差异审核只用于源 PSD 更新，其他入口按已有授权执行，不填写空审核表。

两份说明共同参与每轮对比：第一份解释源稿与 `_UI` 的差异，第二份解释整理稿到 Prefab、绑定及已有功能接入的差异。审核前读取两份，执行后分别更新对应阶段并关联，不能仅维护减法说明。

## 存放与关联

沿用项目允许的现有界面记录目录，保持在 Unity 导入范围外。PLink 可使用 `AIArchive/reports/<面板名>/`。固定文件：

- `01-PSD修改说明.md`，见 [模板](../templates/psd-change-record.md)。
- `02-Prefab减法与布局说明.md`，见 [模板](../templates/prefab-adjustment-record.md)。

实际资产路径、图层决策和验证结果放项目记录；通用流程放个人 Skill。项目文件引用遵守项目相对路径规范。使用记录编号关联同一轮两个文件，不以编号生成新的 `_UI` 或交付目录。

## 版本与恢复证据

保留历史输入、导出事件及结果摘要，不用当前摘要覆盖旧事件。第二份导出所用 PSD 摘要须对应第一份被使用的整理稿版本。摘要用于识别变化，不能恢复文件、布局或引用。

正式导出前结合当前说明中的历史记录和当前实际资产补齐可恢复基线：节点身份与结构、适配参数、布局组件、模板及滚动配置、文字配置、业务组件、序列化引用、`.meta` / GUID、受影响的外部引用。参数不足以恢复的内容保留可恢复资产快照，并记录来源。不能因为已有 MD 就跳过实际资产，也不能只留哈希开始覆盖。

固定 `_UI` 是持续维护的整理稿；源稿保留不动。需要恢复备份时按项目允许位置保存，不将备份变成默认新工作稿、隔离候选或新的 MD。没有历史证据时注明未知，以当前可核实的资产建立基线。

## 按实际阶段记录

1. **差异审核及整理前后。** 源 PSD 更新先只读对比新源与当前固定 `_UI`，结合当前说明中的历史记录分清新设计、历史整理及人工修正，记录拟处理差异和用户对本次清单的同意；审核通过前不改固定 `_UI`。笼统完整流程授权不能替代本次差异审核。 在第一份说明记录本次源稿、固定整理稿路径、输入版本、实际改名/分组/可见性/尺寸变化及依据。保留人工修正，保存重开后核对结构、文本、视觉及源文件未变。
2. **正式导出前。** 在第二份说明关联整理稿检查与可恢复适配基线，记录现成工具菜单/按钮或同一方法入口、实际 Importer、当前配置、正式输出路径、已有授权范围和共享资源影响。默认直接走正式生成路径，不增加候选导出或合并前置。
3. **正式导出后。** 追加导出事件、输入和输出版本、实际日志与失败状态。将结果与基线和设计快速对比，记录哪些适配恢复、哪些变化需按新设计处理，及处理后的字段和依据。区分工具新写出、资源复用与明确获准的迁移。
4. **绑定与业务。** 记录“现成工具生成 → 必要手写业务引用修复 → 编译/类型加载 → 现成工具刷新 → 引用和适配复核”。代码仅修复受影响旧逻辑；属于以前已实现功能的差异补全适配并记录原调用链依据，从未实现功能列为缺口，不自动补做，不手改生成物，不修改框架、导入器、生成器或公共工具源码；能力不足记录具体限制。
5. **验证。** 分别填写静态、编译、显示、运行与交互实际结果。失败后不填写后续成功；未执行项明确注明。记录最终正式状态、残余问题与恢复内容去向。

源 PSD 更新的具体差异经用户审核同意后，按“更新固定 `_UI` → 工具正式生成 Prefab → 按 MD 比较恢复适配并更新减法 → 工具生成代码”连续执行；其他入口不要求这项源更新审核。同一已审核范围后续不重复确认。只有真实冲突或超出授权的变更才需要具体澄清；操作计划与操作结果分开，不能把已授权写成已完成。失败时记录已写文件和当前状态，文件还原由用户处理，不自动回滚。

## 后续修订

- 源设计更新按主流程维护固定 `_UI` 和正式资源，追加原两份说明；当前说明中的历史记录用于快速理解，当前实际资产用于补齐最新基线。
- 用户只改适配时，在原第二份说明记录最新参数与实际验证，不重导出或重跑绑定。若兼有节点/绑定变化，按真实范围处理并记录。
- 只改手写业务且节点、组件与绑定不变时，不新建 PSD/Prefab 说明，不填写空的正式修改审批表；相关导出、生成和刷新写本次不适用。
- 同轮补充修改保留曾被下一阶段使用的版本证据，不复制历史表格形成竞争的当前方案。当前状态以最新实际保存、验证的记录为准。
